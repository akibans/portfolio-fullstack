# Full Stack Portfolio Website

A personal **Frontend / Junior Full Stack Developer portfolio** built to showcase my projects and skills with a modern, responsive UI.

🔗 **Live Demo:** [https://akib-fullstack-portfolio.netlify.app/](https://akib-fullstack-portfolio.netlify.app/)

---

## 🚀 Features
- **Responsive Design:** Optimized for mobile, tablet, and desktop.
- **Modern UI:** Clean aesthetic with smooth animations and dark mode support.
- **Fast Performance:** Built with Vite for rapid development and optimized production builds.

---

## 🧰 Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, React.js (Planned)
- **Tooling:** Vite, Git, GitHub
- **Deployment:** Netlify / Vercel

## 📦 Installation & Usage

1. **Clone the repository:**
   ```sh
   git clone https://github.com/akibans/portfolio-fullstack.git
   cd portfolio-fullstack
   ```

2. **Install dependencies:**
   ```sh
   npm install
   ```

3. **Run the development server:**
   ```sh
   npm run dev
   ```

4. **Build for production:**
   ```sh
   npm run build
   ```
